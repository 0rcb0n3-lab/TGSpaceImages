# Публикация изображений космической тематики в Telegram канал.

Проект представляет собой набор автономных скриптов для автоматизации контента в Telegram. Система собирает космические снимки через API NASA (сервисы APOD, EPIC) и SpaceX, сохраняет их в директорию ```Space_photos``` и передает боту для публикации. Поддерживаются два режима работы: ручной запуск и автоматическая рассылка.

## Функционал

Проект включает следующие скрипты:

#### 1. `fetch_apod_images.py`
Скачивает случайные снимки **Astronomy Picture of the Day (APOD)** от NASA.

#### 2. `fetch_epic_images.py`
Скачивает снимки Земли с камеры **EPIC** (Earth Polychromatic Imaging Camera) со спутника.

#### 3. `fetch_spacex_images.py`
Скачивает фотографии запусков ракет SpaceX.

#### 4. `tgbot_auto_posting.py`
Бесконечно отправляет случайные фото из папки `Space_photos` в Telegram-канал с заданным интервалом.

#### 5. `tgbot_post_image.py`

Отправит одно случайное фото из папки ```Space_photos```.

#### 6. `download_images.py`
Вспомогательный модуль для загрузки и сохранения изображений.


# Как пользоваться

1. **Необходимо использовать виртуальное окружение:**

Для корректной работы требуется ``Python версии ==  3.10``

Создайте и активируйте виртуальное окружение.

 ```
python -m venv venv

venv\Scripts\activate 
```

2. **Установите необходимые модули:**
```
pip install -r requirements.txt
```

> __Важно__: _используется версия 13.15 python-telegram-bot, так как более новые версии (20+) используют асинхронный API._

3. **Создайте `.env` файл в корне проекта и укажите следующее:**

```
NASA_API_KEY=ваш_ключ_NASA
TGBOT_TOKEN=токен_вашего_телеграм_бота
TG_CHAT_ID=XXXXXXXXXX  # ID канала или чата / @your_channel_name
POST_DELAY_HOURS=указать кол-во часов
```

> __Важно__: *Для получения **API ключа NASA** необходимо зарегистрироваться на ```https://api.nasa.gov/#signUp ```*

>__Важно__: *Создать бота и получить **TOKEN** ```https://telegram.me/BotFather```*

# Как работают скрипты

## Скачивание фото

### APOD (фото дня от NASA)

Скрипт предназначен для скачивания изображений Astronomy Picture of the Day (APOD) от NASA с использованием их API.

>__Важно__: *!!! API ключ обязателен для работы*

```
python fetch_apod_images.py --count 6

#Можно изменить кол-во снимков --count 3 - три снимка, без аргументов по умолчанию - 6
```

### EPIC (фото Земли)

Скрипт предназначен для скачивания изображений с камеры EPIC (Earth Polychromatic Imaging Camera) от NASA с использованием их API.

>__Важно__: *!!! API ключ обязателен для работы*

```
python fetch_epic_images.py --count 4

#Можно изменить кол-во снимков --count 2 - два снимка, без аргументов по умолчанию - 3 
```

### SpaceX (запуски)

Скрипт обращается к API SpaceX по указанному ID запуска, получает список изображений (фотографий старта, полёта и посадки)

>*API ключ не требуется*

```
python fetch_spacex_images.py --launch-id latest

# По умолчанию — архивный запуск 5eb87d47ffd86e000604b38a,
но можно указать --launch-id latest для последнего запуска.
```

> **Фото с скриптов сохраняются в папку Space_photos/.**
---

### Отправка фото в Telegram

Запустить автопостинг (по умолчанию — каждые 4 часа)

Частоту публикаций можно регулировать через переменную окружения ```POST_DELAY_HOURS=указать кол-во часов``` в ```.env``` файле или по примеру ниже:

```
python tgbot_auto_posting.py --delay 4

#Можно изменить интервал: --delay 2 — каждые 2 часа.
```

Скрипт работает в бесконечном цикле: перемешивает файлы и поочередно их публикует. После завершения очереди процесс запускается заново. Программа выполняется в фоновом режиме и останавливается вручную комбинацией клавиш ```Ctrl + C```.

## Как это работает

1. Скрипты скачивают изображения и сохраняют в папке ```Space_photos/```.
2. Бот берёт фото из этой папки и отправляет их в Telegram.
3. Фото выбираются в случайном порядке, после каждого поста — пауза.
